# My-portfolio
A fully responsive, interactive personal portfolio website built from scratch with pure HTML, CSS, and vanilla JavaScript, featuring custom cursor animations and a dark cyber-aesthetic.
Designed with a modern, dark cyber-aesthetic to showcase my skills, projects, and passion for software development, artificial intelligence, and cybersecurity.

## ✨ Features

- **Custom Interactive Cursor**: A unique glowing cursor and trailing ring that reacts to hover states using JavaScript `requestAnimationFrame`.
- **Scroll Reveal Animations**: Smooth fade-up animations powered by the `IntersectionObserver` API to dynamically reveal content as you scroll.
- **Cyber-Aesthetic UI**: A sleek, dark theme utilizing modern CSS variables, smooth scroll behavior, and subtle background glow effects.
- **Fully Responsive**: Adapts seamlessly to all screen sizes, from mobile phones to ultra-wide desktop monitors using modern flexbox and grid layouts.
- **Clean Architecture**: Codebase is modular and separated cleanly into HTML structure, CSS styling, and JavaScript logic.

## 🛠️ Built With

- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox, CSS Grid, Media Queries, Keyframe Animations)
- **Vanilla JavaScript** (DOM manipulation, Event Listeners, Observers)

## 🚀 Getting Started

To view this project locally:

1. Clone or download the repository to your local machine.
2. Open the `index.html` file in any modern web browser, or use a local server extension.
